# QQ 空间 Pages 媒体读取与下载

## 支持范围

Page 将 QQ 空间说说中的资源规范为统一媒体对象：

- `image`：QQ 空间原图；
- `video`：在线播放地址、封面和时长；
- `audio`：在线音频；
- `file`：普通附件及无法进一步识别的附件类型。

旧版 `images` 字段继续保留，避免影响既有 Page 和调用方。新 Page 优先读取 `media`，没有该字段时再回退到 `images`。

## 表情与图片边界

解析器会排除 QQ 空间官方表情资源：

- `/qzone/em/`、`emotion`、`emoticon`；
- `/aoi/img/qz_em/`；
- QQ 商城表情资源 `/club/item/parcel/`。

因此，正文、评论或点赞人昵称中的表情不会再被当成说说配图。头像资源沿用原有排除规则。

## 视频与音频预览

视频优先读取 QQ 返回的 `pic[].video_info` 在线播放地址，并使用同一图片项作为封面。浏览器只预加载媒体元数据，不在预览前下载完整文件，也不会保存到插件目录。

音频使用浏览器原生播放器并采用相同的元数据预加载策略。QQ 返回的签名 URL 可能过期；过期后刷新动态或详情即可取得新地址。

## 原文件下载

每个媒体对象都保留 QQ 返回的原始地址作为 `download_url`。Page 的“下载原文件”入口直接访问该地址：

- 不经过插件代理；
- 不做转码、缩放或压缩；
- 下载速度由浏览器到 QQ CDN 的直连链路决定。

浏览器可能根据跨域响应头直接保存文件，或先在新标签页打开媒体；两种情况访问的都是同一个原始资源地址。
